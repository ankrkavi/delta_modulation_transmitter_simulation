# Delta Modulation Transmitter Simulator

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or double-click `index.html`.
4. Press **Start** or **Step**.

## Project files
- index.html
- style.css
- script.js

No Node.js, backend, database, or external libraries are required.

## Demonstration
Try these presets:
- Normal
- Slope Overload
- Granular Noise
- High Sampling
- Low Sampling
- Small Δ
- Large Δ

For viva, demonstrate one sample:
Input x[n] → compare with previous staircase → generate 1/0 → add/subtract Δ → feed staircase back to comparator.
