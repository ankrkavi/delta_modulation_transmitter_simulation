📘 Learning Mode

Delta Modulation sends the direction of change, not the absolute amplitude.

If x[n] > x̂[n−1]
b[n] = 1
x̂[n] = x̂[n−1] + Δ
Otherwise
b[n] = 0
x̂[n] = x̂[n−1] − Δ
Key idea
The feedback staircase becomes the reference for the next comparison.
